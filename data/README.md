# Dataset

Download `marketing_AB.csv` from the [Kaggle Marketing A/B Testing dataset](https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing) and place it in this folder. The raw dataset is not committed to this repository.

The notebook expects the path `data/marketing_AB.csv`. It contains one row per user and the original columns `user id`, `test group`, `converted`, `total ads`, `most ads day`, and `most ads hour`, plus an exported row-index column that the notebook drops.
